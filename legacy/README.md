# Scripts Legados (Versões Iniciais / Tutoriais)

Esta pasta contém as versões didáticas e tutoriais originais mantidas apenas para fins de referência histórica e estudo:

- `AIVirtualMouse.py`: Script didático original baseado no tutorial clássico (utiliza a biblioteca legada `autopy`).
- `HandTrackingModule.py`: Módulo auxiliar clássico de detecção de mãos utilizado pelo `AIVirtualMouse.py`.

> [!NOTE]
> Para o sistema oficial de alta performance e uso no Totem/Jogos SENAI, utilize o ponto de entrada unificado na raiz:
> - `py main.py` (Mouse Virtual + Área de Testes com jogos)
> - `py mac_touchless_pro.py` (Modo Touchless Pro)
> - `py ironman_touchless_pro.py` (Modo Jarvis Ironman)
